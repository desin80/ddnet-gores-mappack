# DDNet Gores Mappack

[中文](README.md) | [English](README.en.md)

This repository contains gores maps collected personally.

Source: KoG (King of Gores), Axiom, 0XF, EGO (Eternal Gores)

> metadata may not be 100% accurate.

## Contents

- `maps/`
  Raw `.map` files.
- `maplists/`
  Difficulty-based JSON map lists.
- `metadata/all-metadata.json`
  Flattened export of all map metadata.
- `metadata/stats.json`
  Map counts by difficulty.
